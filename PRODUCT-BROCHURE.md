│  │  - Runtime                       │  │
│  └─────────────────────────────────┘  │
│  ┌─────────────────────────────────┐  │
│  │  3 Webview Panels               │  │
│  │  - Chat Panel (19KB)            │  │

                │ REST API (Axios)
┌───────────────▼───────────────────────┐

## 🚀 Getting Started

### **Quick Installation (5 Minutes)**

#### **Step 1: Clone Repository**
```bash
git clone https://github.com/juleszackaria-lab/Sudo-studio.git
cd Sudo-studio
```

#### **Step 2: Install Dependencies**

**Extension:**
```bash
cd sudo-ai-extension
npm install
```

**Backend:**
```bash
cd ../backend
npm install
```

**Python Runtime:**
```bash
cd runtime
pip install -r requirements.txt
```

#### **Step 3: Start Services**

**Terminal 1 - Backend:**
```bash
cd backend
node server.js
# Server running on port 5000
```

**Terminal 2 - AI Runtime:**
```bash
cd backend/runtime
python server.enterprise.py
# Runtime running on port 6000
```

**Terminal 3 - Extension:**
```bash
code sudo-ai-extension
# Press F5 to launch Extension Development Host
```

#### **Step 4: First Use**

1. Open VSCode Extension Development Host
2. Click Sudo Studio icon (robot) in Activity Bar
3. Open **AI Chat** from Dashboard
4. Type: "Hello! Can you help me with Python?"
5. See beautiful AI response with formatting

**Congratulations!** 🎉 You're now using Sudo Studio Enterprise.
