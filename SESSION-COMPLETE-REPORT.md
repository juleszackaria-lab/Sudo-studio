## 🏗️ ARCHITECTURE FINALE

### Structure Extension
```
Extension VSCode
├── Extension Entry (extension.js)
│   ├── activate() - Initialisation
│   ├── registerProviders() - 7 providers
│   ├── registerCommands() - 35+ commands
│   └── setupEventListeners() - Event system
│
├── Services Layer
│   ├── BackendService - API communication
│   └── StateManager - Reactive state
│
├── Providers Layer (Sidebar)
│   ├── DashboardProvider
│   ├── ChatProvider
│   ├── DoctorProvider
│   ├── SDKProvider
│   ├── DevOpsProvider
│   ├── EnvironmentProvider
│   └── RuntimeProvider
│
└── Panels Layer (Webviews)
    ├── ChatPanel - HTML/CSS/JS moderne
    ├── DoctorPanel - Cards et AutoFix
    └── SDKPanel - Grid et progress bars
```

### Communication Flow
```
User Action
    ↓
VSCode Command
    ↓
Extension Handler
    ↓
StateManager (update state)
    ↓
BackendService (API call)
    ↓
Backend Express (port 5000)
    ↓
Python Runtime (port 6000)
    ↓
AI Model (inference)
    ↓
Response
    ↓
StateManager (emit event)
    ↓
Providers (refresh)
    ↓
UI Update
```
