## Slide 14: Getting Started

### **Quick Start Process** (5 Minutes)

**Step 1: Download**
```bash
git clone https://github.com/juleszackaria-lab/Sudo-studio.git
cd Sudo-studio
```

**Step 2: Install Dependencies**
```bash
cd sudo-ai-extension && npm install
cd ../backend && npm install
cd runtime && pip install -r requirements.txt
```

**Step 3: Start Services**
```bash
# Terminal 1: Backend
node backend/server.js

# Terminal 2: AI Runtime
python backend/runtime/server.enterprise.py

# Terminal 3: VSCode Extension
code sudo-ai-extension
# Press F5 to launch
```

**Step 4: Use!**
- Open Sudo Studio sidebar
- Start AI Chat
- Run System Doctor
- Install SDKs
- Generate DevOps files
